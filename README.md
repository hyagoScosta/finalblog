# wedresenhasite

Site do grupo com chat em tempo real via **Socket.IO** e servidor **Node.js/Express**.

## 🚀 Executar localmente

```bash
npm install
npm start
```

Acesse: [http://localhost:3000](http://localhost:3000)

## 🌐 Deploy no Render

1. Crie conta em https://render.com
2. Conecte este repositório ao Render
3. Configure:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. Deploy automático 🎉
